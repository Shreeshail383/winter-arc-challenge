
# Day 002 — Add Digits

- Platform: LeetCode
- Language: Python
- Pattern: Digit Manipulation

## Approach
Extract each digit using modulo 10, add the digits,
and repeat until only one digit remains.

## Complexity
- Time: O(log² n)
- Space: O(1)
